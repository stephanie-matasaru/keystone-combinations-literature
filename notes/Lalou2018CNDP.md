# The Critical Node Detection Problem in networks: A survey
**Citation:** Lalou2018CNDP · **PDF:** not included (paywalled), https://doi.org/10.1016/j.cosrev.2018.02.002
**Read:** abstract and how other papers describe it

## What it's about
Survey of the Critical Node Detection Problem (CNDP): finding the set of nodes whose deletion maximally degrades network connectivity according to a chosen metric. Classifies problem variants and solution algorithms based on the connectivity metrics and constraints used. Applications include network security, transportation planning and emergency evacuation.
